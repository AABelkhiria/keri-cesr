# keri-cesr

CESR primitives and, behind the `crypto` feature, KERI cryptography in Rust. The behavior and wire
bytes match [signify-ts](https://github.com/WebOfTrust/signify-ts), checked against fixtures it
generates.

Extracted from the signify-rs project.

## Modules

| Module | Purpose |
|---|---|
| `base64`, `bytes` | URL-safe Base64 and byte/integer helpers with explicit bounds |
| `code` | Derivation code tables and sizes |
| `matter` | Qualified material: parse and encode `qb64`, `qb2` |
| `indexer` | Indexed signature material |
| `counter` | KERI v1 count codes |
| `number`, `sequence` | CESR numbers and sequence numbers |
| `bexter`, `path` | Base64 text and SAD paths |
| `crypto` (feature) | Digests (BLAKE3), Ed25519 and P-256 verification, Ed25519 signing, Argon2id salt derivation, X25519 sealed-box encryption |

Covers the CESR v1 subset implemented by signify-ts; no CESR v2 or genus tables.

The `crypto` feature is off by default, so CESR alone builds with only `base64` and `zeroize`.

## Use

```bash
cargo add keri-cesr --features crypto
```

```rust
use keri_cesr::{code::DerivationCode, matter::QualifiedMaterial};
use keri_cesr::crypto::{
    signer::{SignaturePlacement, Signer},
    verifier::KeyTransferability,
};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let material = QualifiedMaterial::new(DerivationCode::BLAKE3_256, &[0_u8; 32])?;
    assert_eq!(material.qb64()?, "EAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA");

    let signer = Signer::from_seed(&[7_u8; 32], KeyTransferability::Transferable)?;
    let signature = signer.sign_indexed(b"example serialization", SignaturePlacement::both_lists(0))?;
    signer.verifier().verify(signature.raw(), b"example serialization")?;
    Ok(())
}
```

## Prerequisites

- Rust 1.97 or newer (`rustup` installs the toolchain pinned in `rust-toolchain.toml`).
- Nightly Rust and `cargo-fuzz`, only for fuzzing.
- Node 22 or newer, only to regenerate the fixtures.

## Build and test

```bash
cargo fmt --all -- --check
cargo clippy --all-targets --all-features
cargo test --no-default-features
cargo test --all-features
cargo deny check
```

## Reference fixtures

`fixtures/` holds the expected outputs, generated by signify-ts at the commit pinned in
`tools/reference-vectors/package.json`. Tests read them and never need Node or the network.
Each fixture directory has a README with its provenance.

```bash
npm ci --prefix tools/reference-vectors
npm run --prefix tools/reference-vectors check      # regenerate and fail if anything changed
npm run --prefix tools/reference-vectors generate   # regenerate after an intended change
```

## Fuzzing

```bash
cargo +nightly fuzz list
cargo +nightly fuzz run matter
```
