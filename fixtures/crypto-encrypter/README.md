After building the pinned checkout, reproduce and compare the fixture from the repository root:

```bash
npm ci --prefix tools/reference-vectors
node tools/reference-vectors/crypto_encrypter.mjs --check
```

The fixture proves the exact Ed25519-to-X25519 recipient conversion in both raw and qualified
forms. It also proves the reverse interoperability direction: the pinned
`libsodium-wrappers-sumo` dependency successfully opens exact sealed-box ciphertexts generated by
Rust with deterministic public test-only ephemeral secrets.

Production encryption never accepts caller-supplied entropy and obtains a fresh 32-byte ephemeral
secret from the operating-system CSPRNG. Fixed entropy exists only in private unit-test code paths.
The fixture also records two deliberate safety differences: Rust rejects non-contributory X25519
public keys, and its typed API cannot silently label arbitrary qualified material as a signing seed.
